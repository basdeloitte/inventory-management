Key Patterns & Constraints

Reactivity Pattern

Raw data in refs (allOrders, inventoryItems). Derived values in computed properties. Filter composable is a singleton — all views share the same reactive state without prop drilling.

In-Memory Data

No database. All 7 JSON files load once at startup. Mutations (tasks, purchase orders) exist only for the server lifetime. Data covers Jan–Dec 2025. Revenue goal: $800K/month or $9.6M YTD.

Common Gotchas

  • Use unique :key in v-for (sku/month, not index)
  • Validate dates before calling .getMonth()
  • Inventory has no month filter (no time dimension)
  • Sync Pydantic models when JSON structure changes
